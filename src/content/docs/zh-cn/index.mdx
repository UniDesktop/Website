## 为什么需要 UDA

开发跨平台桌面应用，同一个功能往往要写五遍：Windows 上用 `SystemParametersInfoW`，Linux 上则是 `gsettings`、`qdbus`、`swww`、`hyprpaper` 各写一套——失败模式各异、会话假设不同，也没有统一的类型系统。

UDA 用一套**能力驱动（capability-driven）**的 Rust API 取代这种碎片化：探测运行环境、选择可用后端、优雅降级，而不是直接崩溃。

## 三大入口

| 入口 | 适用场景 |
|------|----------|
| Rust crate | 原生 Rust 应用，直接用 `AppearanceManager`、`TrayManager` 等 trait |
| C-ABI (`include/uda.h`) | C/C++、或需要稳定 ABI 的场景 |
| Python / Node.js SDK | `examples/python/uda.py`（ctypes）与 `examples/nodejs/uda.js`（koffi），零原生编译步骤 |
